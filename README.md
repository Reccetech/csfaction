# Élèves d’abord / Students First

Advocacy site by concerned parents of CSF students. French default; English at `/en/`.

## Local

```bash
cd website
npm run dev      # http://localhost:4321
npm run build
npm run preview
```

## Structure

| FR | EN |
|----|----|
| `/` | `/en/` |
| `/effectif` | `/en/enrolment` |
| `/frais-juridiques` | `/en/legal-fees` |
| `/reactions` | `/en/pushback` |

Set the Change.org URL in `src/site.config.ts` (`changeOrgUrl`).
